# Test Planning Coach

## 1. 목적

이 Skill의 목적은 수강생이 개발한 기능이나 API에 대한 테스트 시나리오를 설계하고, 이를 검증할 수 있는 자동화 테스트 코드(예: Python pytest, Node.js Jest 등)를 구축하여 코드 안정성을 극대화하는 것입니다.

## 2. 사용 상황

- 새로운 기능 구현 또는 리팩토링 완료 후 코드 검증이 필요할 때
- 수동 테스트 외에 CI/CD 또는 CLI 환경에서 구동될 자동화 테스트 스크립트 작성이 필요할 때
- 테스트 시나리오 문서(`test-scenario.md`)를 템플릿에 맞추어 작성하고 싶을 때
- 외부 API 연동 기능의 Mocking 테스트가 필요할 때

## 3. 입력 정보

- 테스트 대상 소스 코드 및 디렉토리 구조
- 테스트 대상 API 명세 또는 비즈니스 로직 요구사항
- 예외 상황(Exception Cases) 정의 정보

## 4. 작업 절차

1. **시나리오 작성**: 정상 작동(Happy Path), 경계값 처리, 예외(Exception) 상황 정의
2. **테스트 템플릿 작성**: `templates/test-scenario-template.md` 포맷에 따라 테스트 시나리오 문서 생성
3. **테스트 코드 작성**: 테스트 대상 언어/프레임워크에 최적화된 테스트 러너용 자동화 스크립트 작성 (`*_test.py` 또는 `*.test.js`)
   - 외부 의존성(예: OpenAI API 등)이 있을 경우 Mock 라이브러리를 사용해 모킹 처리
4. **검증 커맨드 안내**: 테스트를 수행할 수 있는 터미널 실행 명령어 제공 및 검증 방법 제시

## 5. 산출물 형식

Claude는 테스트 계획 및 구현 결과를 아래 Markdown 형식으로 제공합니다.

```markdown
# 테스트 설계 및 자동화 결과

## 1. 테스트 시나리오 (`test-scenario.md`)
*생성 또는 수정한 테스트 시나리오 문서 요약 및 링크 제공*

## 2. 자동화 테스트 코드
- 파일 위치: `tests/test_...`
- 사용 프레임워크: pytest / jest 등

```python
# 실제 작성된 테스트 코드 삽입
```

## 3. 테스트 실행 명령어
```bash
# 실행할 명령어 예시
pytest tests/ -v
```

## 4. 기대 결과 및 확인 방법
- 정상 성공 시 터미널 출력 예시 및 성공 판정 기준 제시
```
