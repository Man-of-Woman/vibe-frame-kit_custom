## 점진적 설계 및 구현 요청 사항
다음 4가지 단계를 순서대로 진행하고, 각 단계마다 설계 문서 작성 및 코드 구현을 마친 후 결과를 보고해줘.

### [1단계] 데이터 및 도메인 모델 설계
- templates/domain-model-template.md 템플릿을 참고하여 이 기능에 필요한 데이터 구조와 엔티티 모델을 정의해줘.
- (필요 시) 데이터베이스 스키마나 인메모리/Pydantic 데이터 구조 코드를 구현해줘.

### [2단계] API 명세 및 구조 설계
- templates/api-spec-template.md 템플릿을 참고하여 REST API 엔드포인트 명세를 작성해줘.
- FastAPI의 `router`, `schema`, `service` 계층이 분리되도록 코드를 작성해줘.
- 실제 API Key 등 민감 정보가 코드에 직접 작성되지 않도록 보안 원칙을 지켜줘.

### [3단계] AI 에이전트 워크플로우 설계 (해당 시)
- templates/agent-workflow-template.md 템플릿을 참고하여 여러 단계의 AI 처리 흐름, 프롬프트 파이프라인, 도구 사용 방식을 정의하고 구현해줘.

### [4단계] 테스트 시나리오 작성 및 자동화 테스트 코드 구현
- templates/test-scenario-template.md 템플릿을 참고하여 정상, 예외, 경계값 케이스를 검증하는 테스트 시나리오를 작성해줘.
- 구현된 기능과 API를 자동으로 검증할 수 있는 테스트 스크립트(*_test.py 또는 *.test.js)를 작성하고 검증 결과를 알려줘.
