# Test Planning Coach

## 1. 목적
이 Skill의 목적은 수강생이 개발한 기능이나 API에 대한 테스트 시나리오를 설계하고, 이를 검증할 수 있는 자동화 테스트 코드(pytest, jest 등)를 작성하는 것입니다.

## 2. 사용 상황
- 새로운 기능 구현 또는 리팩토링 완료 후 코드 검증이 필요할 때
- 수동 테스트 외에 CLI 환경에서 구동될 자동화 테스트 스크립트 작성이 필요할 때
- 테스트 시나리오 문서(`test-scenario.md`) 작성이 필요할 때

## 3. 입력 정보
- 테스트 대상 소스 코드 및 디렉토리 구조.
- 테스트 대상 API 명세 또는 비즈니스 로직 요구사항.

## 4. 작업 절차 및 템플릿 참조 규칙
1. 에이전트는 다음 경로의 템플릿을 동적으로 로드(`view_file`)하여 작성 항목을 파악합니다: `{{INSTALL_PATH}}/templates/test-scenario-template.md`.
2. 정상 경로, 경계값, 예외 상황에 대한 시나리오를 설계하고 자동화 테스트 코드 파일 및 실행 명령을 작성합니다.
3. 수강생이 테스트 시나리오 설계 원칭이나 AI API 모킹(Mocking) 테스트 코드 작성 예제를 원할 경우, `{{INSTALL_PATH}}/study/test-planning-study.md` 파일을 안내 또는 참조하도록 유도하십시오.

## 5. 테스트 설계 주의사항
- 테스트 실행 명령어는 수강생이 로컬 터미널에서 즉시 복사하여 구동할 수 있도록 구체적인 옵션(`pytest tests/ -v` 등)과 함께 제공합니다.
- 외부 의존성(OpenAI API 등)이 있을 경우 Mock 라이브러리를 사용하여 요금 낭비와 네트워크 지연을 예방합니다.
