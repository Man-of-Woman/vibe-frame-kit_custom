## 1. 작업 개요
Git 원격 저장소가 아직 준비되지 않았거나 연동을 나중에 하고자 하는 사용자의 편의를 위해, 설치 단계에서 Git URL 입력을 강제하지 않고 선택(Optional)으로 건너뛸 수 있도록 개선했습니다. Git URL이 명시되지 않을 경우, 자동으로 Git 자동화 관련 설정을 비활성화하여 동작하도록 파이프라인을 보완했습니다.

## 2. 변경된 파일 목록 및 상세 내용

### 1) [install.ps1](file:///d:/workspace/vibe-frame-kit_custom/install/install.ps1) (PowerShell)
- Git URL 입력 프롬프트 안내를 `Optional` 문구를 포함해 변경하고, Enter(공백) 입력을 허용하도록 정규식 검사 앞 단의 체크 조건을 완화했습니다.
- `$GitUrl` 변수가 공백일 경우 `config.toml` 자동 생성 단계에서 `auto_commit_push = false`로 자동 치환 및 생성하여 저장하도록 분기 구문을 추가했습니다.

### 2) [install.sh](file:///d:/workspace/vibe-frame-kit_custom/install/install.sh) (Bash)
- PowerShell과 일관성 있게 Git URL 프롬프트에서 빈 값 입력을 허용하도록 루프 조건을 완화했습니다.
- `$GIT_URL`이 빈 문자열일 경우, python 또는 sed 가 `common.config.sample.toml`을 파싱할 때 `auto_commit_push = true` 구문을 `auto_commit_push = false`로, `remote_repository_url`은 빈 문자열(`""`)로 강제 매핑하여 결과물인 `config.toml`에 반영하도록 수정했습니다.

---

## 3. 검증 결과
- `install.ps1`을 대화식 실행하고 Git URL 입력을 공백으로 스킵한 결과:
  - 지정한 폴더 내에 `config.toml`이 정상 자동 생성되었습니다.
  - 생성된 설정 내에 `remote_repository_url = ""` 및 `auto_commit_push = false`가 올바르게 적용되어 있음을 확인하고, 생성된 임시 테스트 폴더를 안전하게 소거했습니다.
