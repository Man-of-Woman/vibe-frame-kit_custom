## 1. 작업 개요
본 작업은 vibe-frame-kit 개발 및 실습 완료 시 제출 산출물로 사용되는 **1) 완료 보고서(Walkthrough) 생성 규칙** 및 **2) Git 커밋/푸시 유도 규칙**을 프레임워크 코어 기능으로 정밀 탑재하고, 이를 **3) 설정 파일(`config.toml`)에서 사용자가 On/Off로 유연하게 제어**할 수 있도록 옵션 스위치를 보급하며, **4) 학생 및 강사 안내 문서**를 최신 사양으로 개편하기 위해 수행되었습니다.

## 2. 주요 변경 사항 및 작업 결과

### 1) 설정 샘플 파일 개정 (`common/config/common.config.sample.toml`)
* `common.config.sample.toml` 맨 하단에 에이전트의 완료 행동을 동적으로 제어하기 위한 `[walkthrough]` 및 `[git]` 설정 섹션을 신설하였습니다.
* **`enable_generation` / `enable_metadata_logging`**: 완료 보고서 생성 유무 및 상단 메타데이터(원문, AI 모델, 수행 시간, 소모 토큰) 인용 여부를 켜고 끕니다.
* **`auto_commit_push` / `korean_commit_message`**: 작업 완료 후 자동 Git 커밋/푸시 가이드 제안 여부 및 한글 커밋 강제 여부를 켜고 끕니다.

### 2) 공통 규칙 문서 개편 (`common/RULES.md`)
