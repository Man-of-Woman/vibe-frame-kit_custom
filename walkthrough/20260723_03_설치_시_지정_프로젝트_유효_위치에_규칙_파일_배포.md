# 작업 완료 보고서 (Walkthrough)

> **사용자 작업 지시사항 원문**
> install 스크립트를 변경한다.
> 목적 : common/AGENTS.md 파일을 전역 설정 위치가 아닌 지정 프로젝트 폴더의 유효한 위치에 설치하는 것으로 변경한다.

* **사용 AI 모델명**: Gemini 3.5 Flash (Low)
* **작업 수행 시간**: 약 120초
* **소모 토큰 수**: 약 15,000 토큰

---

## 작업 개요
지정된 프로젝트 폴더(`-SpecifyFolder` 사용 시)의 유효한 위치에 AI 에이전트용 규칙 파일(`AGENTS.md` / `CLAUDE.md`)을 직접 배포하도록 설치 스크립트(`install.ps1`, `install.sh`)를 개선하였습니다.

## 변경 사항 및 상세 내용

### 1. [install.ps1](file:///d:/workspace/vibe-frame-kit_custom/install/install.ps1) 수정
* `$DeployConfigDirectly` 분기 내에 선택한 AI 도구(`$CurrentTool`)에 따른 경로 처리 스위치를 추가하였습니다.
  - **gemini (안티그래비티)**: `<프로젝트 폴더>/.agents/AGENTS.md`
  - **claude**: `<프로젝트 폴더>/CLAUDE.md`
  - **codex**: `<프로젝트 폴더>/AGENTS.md`
* `.agents/` 디렉토리가 없을 시 자동으로 폴더를 생성하고, `common/AGENTS.md` 소스의 플레이스홀더를 사용자가 기입한 설정값으로 치환하여 저장합니다.

### 2. [install.sh](file:///d:/workspace/vibe-frame-kit_custom/install/install.sh) 수정
* PowerShell과 동일하게 `$DEPLOY_CONFIG_DIRECTLY`가 `true`일 때 프로젝트 폴더의 도구별 유효 경로를 파악하고, 폴더 생성 및 `replace_variables` 처리를 수행하도록 구현하였습니다.
