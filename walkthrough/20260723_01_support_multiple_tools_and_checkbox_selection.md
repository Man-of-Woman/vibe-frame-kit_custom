# 작업 완료 보고서

> **작업 지시사항 원문**
> 아래 목적을 반영하여 install uninstall 스크립트를 수정하라.
> 
> 1. 사용 가능한 툴은 하나가 아니라 복수개일 수 있다. 따라서 codex, gemini, claude 를 번호로 하나만 선택하는 현재 방식을 변경하여, 체크박스로 복수개 선택할 수 있도록 한다.
> 2. 툴 선택은 최소한 하나는 선택해야 한다.
> 3. 복수개 선택한 툴 모두에 vibe-frame-kit 을 설치한다.
> 4. uninstall 실행시에는 vibe-frame-kit 이 codex, gemini, claude 중 어느 툴에 설치돼있는지 조사하고, 하나인 경우엔 해당 툴의 킷을 제거할지 물어보고, 둘 이상 설치돼있는 경우에는 체크박스로 복수개 선택할 수 있도록 한다.
> 5. 선택한 툴 환경에 설치된 vibe-frame-kit을 제거한다.

* **사용한 AI 모델**: Gemini 3.5 Flash (Medium)
* **작업 수행 시간**: 약 900초
* **소모 토큰 수**: 약 35,000 토큰 (추정치)

---

## 1. 작업 개요
Vibe Frame Kit의 설치 및 제거 스크립트(`install.ps1`, `install.sh`, `uninstall.ps1`, `uninstall.sh`)를 전면 리팩토링하여, 복수 툴 환경에 대한 다중 선택 설치/제거(체크박스 토글 형태)와 기설치 툴 검색 스캔 기능을 연동했습니다.

---

## 2. 주요 변경 사항 및 작업 결과

### 1) 다중 선택 토글형 체크박스 대화식 UI 구현
* **PowerShell (`install.ps1`, `uninstall.ps1`)**: 콘솔 화면을 클리어해가며 숫자를 입력(예: 1, 1,2 등)하여 `[ ]`과 `[X]` 표시를 토글하는 복수 선택 체크박스 대화 루프를 구현했습니다.
* **Bash (`install.sh`, `uninstall.sh`)**: PowerShell과 동일하게 번호 입력으로 복수 선택 대상을 체크/해제하며 Enter 입력 시 확정되는 대화식 인터페이스를 포팅했습니다. Windows로부터 유입되는 CRLF 인자 대응을 위해 문자 트리밍 처리를 강화했습니다.

### 2) 최소 선택 검증 및 복수 동시 배포/제거 루프
* **설치 루프**: 하나 이상의 툴이 선택되었는지 체크하여 0개 선택 시 설치 진행을 방지(최소 1개 강제)하고, 선택된 모든 툴 환경에 대해 각각 백업 및 파일 전개 복사를 루프를 돌며 수행하도록 개선했습니다.
* **파라미터 파싱 강화**: 명령줄 파라미터(예: `-Tool gemini,claude` 또는 `-t gemini,claude`)로 쉼표로 연결된 문자열을 전달받았을 때, 내부적으로 배열로 분리 파싱 및 유효성 검증을 거친 후 순차 설치하도록 보완했습니다.

### 3) 설치 현황 스캔 및 스마트 제거 시스템 (`uninstall.ps1`, `uninstall.sh`)
* 제거 스크립트 실행 시 각 툴별 핵심 에셋 파일(`RULES.md`) 존재 여부를 통해 현재 프레임워크가 어떤 툴에 배포되어 있는지 자동으로 탐색합니다.
  * **설치본 0개**: 안내 문구 출력 후 즉시 안전 종료.
  * **설치본 1개**: 해당 툴에 대해 Y/N 단일 확인 프롬프트만 작동하여 즉각 제거.
  * **설치본 2개 이상**: 설치가 감지된 환경만 필터링하여 체크박스 다중 선택 메뉴를 표출하고, 선택받은 툴들을 동시에 제거.

### 4) 안정성 보강 (에러 핸들링 및 인코딩)
* **백업 에러 무해화**: 에디터나 다른 에이전트의 구동으로 타겟 규칙 파일(`CLAUDE.md` / `AGENTS.md`)에 락(Lock)이 걸렸을 때 전체 복사가 중단되는 문제를 방지하기 위해, rules 파일 백업 단락을 개별 try-catch로 래핑하여 에러 격리 처리를 적용했습니다.
* **BOM 없는 UTF-8 및 LF 전격 포팅**: Python 스크립트 도구를 호출해 shebang 헤더 손상과 UTF-8 BOM 바이트로 인한 WSL Bash 구동 시 shebang 인식 문제를 원천 차단하고 완전한 LF(Line Feed) 포맷으로 교정했습니다.

## 3. 검증 결과
* **다중 설치 검증**: `-Tool gemini,claude` 입력을 통해 두 환경에 백업 및 복사, ignore 파일 생성, TOML 인젝션이 에러 없이 원팩으로 실행됨을 확인했습니다.
* **스캔 및 스마트 제거 검증**:
  1. 2개 설치 시: 제거 스크립트 무옵션 실행 시 다중 선택 체크박스가 정상 출현함을 검증했습니다.
  2. 1개 설치 시: 1개 제거 후 잔여 1개인 상태에서 Y/N 확인 팝업만 동작함을 검증했습니다.
  3. 0개 설치 시: 아무것도 없다는 문구와 함께 즉각 복구 종료됨을 확인했습니다.
* **WSL/Bash 호환 검증**: WSL 환경 내에서 동일한 다중 설치/스캔 삭제 시나리오가 완벽히 구동됨을 테스트 완료했습니다.
