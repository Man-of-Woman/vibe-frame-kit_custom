## 1. 작업 개요
오리지널 버전인 `common/README.md` 문서의 세부 가이드 라인(소개 글, 사용 대상군, 세부 개발 절차 설명, 사용 예시 모범 예문, 개발 주의사항 등)을 루트 `README.md` 문서로 완전히 병합 및 이식하였습니다. 또한 물리 저장소의 폴더 구조와 실제 설치 환경의 전개 방식을 완벽하게 대조 설명하였고, 역할이 종료된 `common/README.md`를 삭제 완료했습니다.

## 2. 주요 변경 사항 및 작업 결과

### 1) 오리지널 상세 설명 병합 (`README.md` 리팩토링)
* **소개 및 대상군 구체화**: AI 페어 프로그래밍 진행 시 Kit가 제시하는 5대 표준(요구사항 우선, MVP 지향 등)과 적합한 타겟 대상군 설명을 병합해 상단부를 보완했습니다.
* **상세 개발 프로세스 해설**: 9단계 개발 프로세스의 각 단계별 상세 동작 목적과 AI 에이전트의 구체적 역할을 매핑한 테이블을 추가했습니다.
* **사용 예시 및 주의사항 복원**: 실제 회의록 요약 프로젝트에 Kit를 적용해 개발을 순차 연동하는 시나리오 예문과 유의사항을 기재했습니다.
* **보안 가이드 보강**: 크레덴셜 유출을 방지하기 위한 보안 점검 및 `.env` 파일 커밋 금지 원칙을 보다 고도화하여 반영했습니다.

### 2) 전체 물리/논리 파일 구조의 완벽한 갱신
* 저장소 내의 실제 물리적 트리 구조(특히 모든 설계 에셋이 `./common/` 하위에 위치하는 점)와 통합 인스톨러 배포 후 타겟 폴더 루트(예: `~/.codex/`) 바로 아래에 플랫하게 복사 및 전개되는 매핑 원리를 상세 구조 트리를 통해 설명했습니다.
* `AGENTS.md`와 `RULES.md` 및 `study/` 폴더 등 최근 추가된 구성 요소들의 기능적 정의와 차이점을 상세 테이블에 설명 보완했습니다.

### 3) 불필요 파일 정리 및 Git 스테이징
* 병합 작업이 완료되어 역할이 끝난 `common/README.md` 파일을 디스크에서 영구 삭제했습니다.
* 수정 및 삭제된 결과들을 Git 스테이징(`git add -A`)에 원활히 등록했습니다.
