> **[지시사항 원문]**
> 다음 요구사항에 맞도록 설치 스크립트를 수정하라.
> 1. 프로젝트 폴더를 지정할 것인지 질문한다.
> 2. 사용자가 프로젝트 폴더를 지정했는데 없다면 생성한다.
> 3. 프로젝트 폴더를 지정하지 않겠다고 한다면 config.toml 파일을 저장하도록 안내한다.
> 4. 프로젝트 폴더를 지정했다면 프로젝트 이름을 물어본다. (기본 값 : 폴더이름)
> 5. 프로젝트 폴더에 config.sample.toml의 기본 값과 프로젝트이름, git 주소, 기타 필요사항을 입력하여 config.toml 파일로 저장한다.

## 1. 작업 개요
통합 설치 스크립트(`install.ps1` 및 `install.sh`)를 개선하여 사용자가 수동으로 config.toml 파일을 복사하고 변경해야 했던 불편함을 해소했습니다. 신규 프로젝트 환경에 맞춰 자동으로 디렉토리를 구축하고, `config.toml`을 최적화된 초기값과 함께 직접 배치할 수 있도록 변경했습니다.

## 2. 변경된 파일 목록 및 상세 내용

### 1) [install.ps1](file:///d:/workspace/vibe-frame-kit_custom/install/install.ps1) (Windows PowerShell용)
- 사용자에게 프로젝트 폴더를 지정하여 바로 배포할 것인지 물어보는 프롬프트(`Do you want to specify a project folder...`)를 도입했습니다.
- 사용자가 폴더 경로를 입력하면 존재 여부를 확인하고, 존재하지 않는다면 `New-Item -ItemType Directory` 명령을 통해 강제 생성합니다.
- 프로젝트명 미입력 시 폴더 최하위의 이름(기본값)을 자동 추출하여 적용합니다.
- 공통 샘플 설정(`common.config.sample.toml`)을 읽어와 `name`, `AGENT_NAME`, `GIT_REMOTE_URL` 등의 가변 인자를 치환한 뒤 타겟 폴더 루트에 `config.toml`로 정상 생성해 줍니다.
- 미지정 시에는 사용자 수동 복사 안내 메시지를 맞춤식으로 출력합니다.

### 2) [install.sh](file:///d:/workspace/vibe-frame-kit_custom/install/install.sh) (Unix/macOS/Linux Bash용)
- `install.ps1`과 동일한 사용자 입력 및 자동화 흐름을 Bash 스크립트에 탑재했습니다.
- 입력된 폴더가 부재할 경우 `mkdir -p`로 디렉토리를 즉시 자동 생성합니다.
- `python3`가 로컬에 설치되어 있는 경우 파이썬 인라인 코드를 사용해 안정적인 파일 치환 처리를 하고, 없는 경우 시스템 환경에 맞춰 macOS(BSD)와 Linux(GNU) 양쪽의 `sed -i` 호환 구문을 적용해 프로젝트 이름 및 Git remote URL 등을 안정적으로 매핑한 `config.toml`을 배치합니다.
