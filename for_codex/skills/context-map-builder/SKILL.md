# Context Map Builder

## 1. 목적

이 Skill의 목적은 복잡한 프로젝트 구조에서 Antigravity가 컨텍스트 크기 제약으로 인해 이전 개발 맥락을 잊어버리지 않도록, 주요 파일 의존성과 활성 컨텍스트 정보를 요약 인덱스로 정리하는 것입니다.

## 2. 사용 상황

- 소스 코드 파일 갯수가 15개 이상으로 늘어났을 때
- 새로운 기능 구현이나 대규모 리팩토링 작업을 시작하기 전
- AI가 이전 파일 구조나 비즈니스 규칙을 혼동하고 엉뚱한 결정을 내릴 때
- 프로젝트 아키텍처 의존성을 명시적으로 표현하고 싶을 때

## 3. 입력 정보

- 전체 프로젝트 소스 코드 및 디렉토리 구조
- 핵심 라이브러리 및 프레임워크 스택 정보
- 현재 활성화되어 작업 중인 파일 및 타겟 모듈 정보

## 4. 작업 절차

1. 주요 컴포넌트 및 파일의 의존성 아키텍처 다이어그램 작성 (Mermaid 활용)
2. 현재 작업의 중심이 되는 활성 파일 목록(Active Context) 명시
3. 코드 수정 시 반드시 준수해야 하는 규칙 및 기술적 제약 사항 정의

## 5. 산출물 형식

Antigravity는 컨텍스트 맵 결과를 Markdown 문서 형식으로 작성하며, 다음 항목을 반드시 포함해야 합니다.

- Mermaid 기반 의존성 다이어그램
- Active Context 파일 리스트
- 아키텍처 및 구현 제약 사항

## 6. 컨텍스트 맵 템플릿

`templates/context-map-template.md` 파일의 형식을 기본 템플릿으로 사용하여 컨텍스트 맵을 작성합니다.
